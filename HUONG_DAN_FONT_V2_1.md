# TV3 UI V2.1 — font dễ đọc hơn

- Chọn **Be Vietnam Pro** (Google Fonts, miễn phí sử dụng dưới giấy phép font mở).
- Font fallback offline: `Segoe UI`, `Arial`, sans-serif.
- Cỡ chữ gốc nâng từ 15px lên 16px và chỉnh typography tại `assets/tv3.css`.
- Giữ nguyên 8 trang HTML, các liên kết, biểu mẫu và `assets/tv3.js`.
- CSS trong `tham-khao-thymeleaf` đã được cập nhật giống bản preview.
- Đây vẫn chỉ là demo UI, chưa có kết nối backend.

## Cập nhật GitHub Pages

Giải nén ZIP và thay các file tương ứng trong repo UI riêng. Nếu muốn cập nhật nhanh, chỉ cần thay file `assets/tv3.css`.

## Nếu thích font Inter

Thay tên font trong CSS từ `Be Vietnam Pro` sang `Inter`, rồi đổi URL Google Fonts tương ứng. Không phải thay HTML hay JavaScript.
